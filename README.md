# 圣经 · 读经笔记

简体和合本圣经全文在线阅读，配个人读经笔记，可按书卷 / 章节 / 关键词检索。

- **经文**：和合本（1919 年出版，已过版权保护期），繁转简
- **诗歌体排版**：约伯记、诗篇、箴言、传道书、雅歌、耶利米哀歌按传统诗歌格式分行
- **读经笔记**：每节经文可展开查看笔记；部分笔记整理自作者 Notion 读经记录
- **搜索**：站内关键词检索经文（首次使用时加载索引）
- 纯静态网站，托管于 GitHub Pages，无需服务器

## 本地预览

用任意静态服务器打开，例如：

```sh
cd /path/to/repo
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 目录结构

```
index.html      整站 SPA 外壳
app.js          路由 / 渲染 / 搜索逻辑
styles.css      样式（含诗歌体悬挂缩进、手机适配）
data/
  books.json    66 卷元数据（中文名、章数、新旧约、诗歌标记）
  cuvz/         每卷一 .b64：gzip+base64 的章->节数组（简体和合本），按需加载解压
notes/
  <book>-<章>.md  每章一个 Markdown 文件，如 notes/psa-002.md（诗篇第 2 章）
```

## 笔记格式（可直接在 GitHub 网页上编辑）

每章一个 Markdown 文件，命名如 `notes/psa-002.md`（诗篇第 2 章）、`notes/mal-001.md`（玛拉基书第 1 章）：

```md
# 诗篇 第2章

## 2:1-3

这里写第 2 章第 1–3 节的笔记……

## 2:4-6

这里写第 2 章第 4–6 节的笔记……

## 本章

这里写整章的笔记（显示在章节顶部）……
```

- `## 2:1-3` —— 范围笔记；`## 5:7` —— 单节笔记；`## 本章` —— 章注
- 正文支持 Markdown 子集：段落、`> ` 引用、`**加粗**`
- 新增笔记：找到对应章节文件（没有就新建 `notes/<书卷>-<3位章号>.md`），按上面格式加 `## ` 段，提交即可
- 书卷缩写见 `data/books.json`（如 psa=诗篇，mal=玛拉基书，gen=创世纪，jhn=约翰福音）
