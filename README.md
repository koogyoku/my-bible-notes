# 圣经 · 读经笔记

简体和合本圣经全文在线阅读，配个人读经笔记，可按书卷 / 章节 / 关键词检索。

- **经文**：和合本（1919 年出版，已过版权保护期），繁转简
- **诗歌体排版**：约伯记、诗篇、箴言、传道书、雅歌、耶利米哀歌按传统诗歌格式分行
- **读经笔记**：每节经文可展开查看笔记；部分笔记整理自作者 Notion 读经记录
- **搜索**：站内关键词检索经文（首次使用时加载索引）
- 纯静态网站，托管于 GitHub Pages，无需服务器

## 本地预览

用任意静态服务器打开，例如：

```sh
cd /path/to/repo
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 目录结构

```
index.html      整站 SPA 外壳
app.js          路由 / 渲染 / 搜索逻辑
styles.css      样式（含诗歌体悬挂缩进、手机适配）
data/
  books.json    66 卷元数据（中文名、章数、新旧约）
  cuv/          每卷一 JSON：章 -> 节数组（简体和合本）
  search_a.json ~ search_d.json   全文检索索引（4 分片，懒加载）
notes/
  <book>.json   笔记：键为 "章:节" / "章:起-止" / "章:0"（章注）
```

## 笔记格式

`notes/<book>.json` 为 JSON 对象，键格式：

- `"3:16"` —— 第 3 章第 16 节的笔记
- `"2:1-3"` —— 第 2 章第 1–3 节的范围笔记
- `"2:0"` —— 第 2 章的章注（显示在章节顶部）

值为 Markdown 子集（段落、`> ` 引用、`**加粗**）。新增笔记只需按此格式编辑对应文件后提交即可。
